# Customer Intelligence & Behavioral Analytics Platform

An end-to-end retail customer analytics project using Python,
SQL, and Power BI to transform 3,900+ customer records into
actionable business insights.

## Tech Stack

- Python
- Pandas
- SQL
- Power BI
- Jupyter Notebook

## Project Workflow

Raw Data
   ↓
Python Data Cleaning & EDA
   ↓
SQL Business Analysis
   ↓
Power BI Dashboard
   ↓
Business Insights & Recommendations

## Key Analysis

- Customer segmentation
- Purchase behavior
- Revenue analysis
- Product performance
- Customer demographics
- Subscription behavior

## Project Files

| Component | File |
|---|---|
| Python Analysis | `customer_behavior_analysis.ipynb` |
| SQL Analysis | `customer_behavior_analysis.sql` |
| Power BI Dashboard | `customer_behavior_dashboard.pbix` |
| Dataset | `customer_shopping_behavior.csv` |
| Report | `customer_behavior_analysis.pdf` |
| Presentation | `customer_behavior_analysis.pptx` |
